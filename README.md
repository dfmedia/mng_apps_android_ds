Android-only atoms, patterns and token exceptions for MNG's 77 Android market apps. Builds on the [MNG Apps Core Design System](https://github.com/dfmedia/mng_apps_core_ds).

## Tokens (generated, DEC-04)

`tokens/MngBrandColors.kt and tokens/flavors/<flavor>/res/values/mng_brand_colors.xml` is generated by Style Dictionary from the Core repo's `tokens/` (DTCG). **Never edit it here**: change the Core data, then run `npm run tokens && npm run build` in `mng_apps_core_ds`. Usage: `MngBrandPalettes.TDP.navbar` (Compose) or `@color/mng_brand_navbar` from the flavor XML; `MngBrandPalettes.forMarket("tdp")`. Status bar for the running Android version (DEC-15): `palette.statusbarFor(Build.VERSION.SDK_INT)` and `palette.statusbarDarkIconsFor(Build.VERSION.SDK_INT)`; in XML `@color/mng_brand_statusbar` and `@bool/mng_brand_statusbar_dark_icons` (Android 15+ values in `res/values-v35/` for the 7 white-top-bar markets). Every color is written from its exact hex bytes; hex and RGB for each market are in Core `docs/BRAND-COLORS.md`.
