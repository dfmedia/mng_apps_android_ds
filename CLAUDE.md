## Scope

This library holds only what Android can't share with Core. Default every item to Core. An item comes here only after Karl approves it as **Android only** on the Core file's ownership pages (see `mng_apps_core_ds/docs/PLATFORM-OWNERSHIP.md`).

Typical Android-only items: Material Symbols glyphs, the notification icon, `statusbar` and `accent` colors, dp/sp sizing, and any Android-only exceptions to Core values.

## Tokens (generated, DEC-04)

`tokens/MngBrandColors.kt and tokens/flavors/<flavor>/res/values/mng_brand_colors.xml` is generated by Style Dictionary from the Core repo's `tokens/` (DTCG). **Never edit it here**: change the Core data, then run `npm run tokens && npm run build` in `mng_apps_core_ds`. Usage: `MngBrandPalettes.TDP.navbar` (Compose) or `@color/mng_brand_navbar` from the flavor XML; `MngBrandPalettes.forMarket("tdp")`. Status bar for the running Android version (DEC-15): `palette.statusbarFor(Build.VERSION.SDK_INT)` and `palette.statusbarDarkIconsFor(Build.VERSION.SDK_INT)`; in XML `@color/mng_brand_statusbar` and `@bool/mng_brand_statusbar_dark_icons` (Android 15+ values in `res/values-v35/` for the 7 markets with a status-bar override: navbar, with dark icons only where the bar is exactly #FFFFFF; TSAR: white bar with dark icons, production correction, `statusbar15Override`). Every color is written from its exact hex bytes; hex and RGB for each market are in Core `docs/BRAND-COLORS.md`.
